INSTALL STEPS
1. Stop the bot and website process.
2. Back up the existing project, database, WhatsApp auth folders, uploads/media, and current .env files.
3. Extract the clean ZIP into the existing project root and choose Merge/Replace.
4. Do NOT replace or delete:
   - .env or portfolio-website/.env
   - auth_info/ or auth_info_baileys/
   - database contents
   - uploads/media or backups
   - portfolio-website/models.js
   - local configuration files you intentionally maintain
5. Install dependencies with `npm ci` if the lockfile is used, or `npm install`.
6. Run:
   npm run check
   npm test
   npm run website:check
   npm run website:test
   npm run audit:release
7. Restart the bot and verify WhatsApp connection.
8. In staging, test `.mulai`, `.mulai cepat`, `.mulai profil`, `.mulai ulang`, `.cari`, and all expanded `.alur` workflows.
9. Verify MongoDB persistence and reload after a bot restart before promoting to production.

IMPORTANT
