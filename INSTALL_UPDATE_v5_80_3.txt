PIR Visuals v5.80.3 — Restore mouse-following animation for all buttons

INSTALLATION
1. Make a backup of the current project.
2. Extract Part 1 into the project root and choose Replace/Overwrite.
3. Extract Part 2 into the same project root and choose Merge/Replace.
4. Do not replace portfolio-website/models.js, .env, database files, uploads, or WhatsApp session folders.
5. Restart the website server.
6. In the browser, hard-refresh with Ctrl + Shift + R.

WHAT CHANGED
- Magnetic pointer-following animation now applies to all native buttons, button-like links, navigation controls, back-to-top, and role=button controls.
- Delegated pointer handling also covers controls rendered dynamically after page load.
- Movement is subtle and bounded, then returns to center when the pointer leaves.
- Disabled controls are excluded.
- Touch-only devices and reduced-motion preferences are respected.
- Existing category color and CTA contrast fixes are preserved.
