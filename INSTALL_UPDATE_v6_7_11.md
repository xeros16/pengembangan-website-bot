# Update PIR Visuals Bot v6.7.11

1. Back up `.env`, database, `uploads`, and `auth_info_baileys`.
2. Stop the bot and website processes.
3. Extract this package over a clean copy of the existing bot folder, or replace the existing folder after backup.
4. Keep the existing `.env` and runtime data folders.
5. No dependency installation is required for this CSS-only update.
6. Start the bot and website again.
7. Hard-refresh the browser with `Ctrl + Shift + R`.
8. Open a designer profile and verify Selected Work images are visible.
9. Open Beranda on mobile and verify the uploaded carousel artwork is clear and fully previewed.

This update bundles Website v3.58.0. It changes presentation only and does not require a database migration.
