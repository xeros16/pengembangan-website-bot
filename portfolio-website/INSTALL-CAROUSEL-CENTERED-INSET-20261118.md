# Instalasi Revisi Carousel — Centered Text Inset

1. Hentikan server Node.js yang sedang berjalan.
2. Ganti seluruh folder `portfolio-website` lama dengan folder `portfolio-website` dari ZIP ini. Jangan hanya menyalin file CSS.
3. Jalankan server dari folder baru menggunakan `npm start`.
4. Buka ulang `http://localhost:3080`, lalu lakukan hard refresh dengan `Ctrl + Shift + R`.

Revisi ini mengubah `server.js` (aturan inline yang langsung dipakai halaman) dan `pir-showcase-editorial.css` (fallback stylesheet). Cache stylesheet juga sudah dinaikkan ke `20261118-copy-centered-70`.
