# Install update v3.61.2

1. Back up the existing website folder and database/uploads.
2. Stop the website server.
3. Replace the `portfolio-website` folder with the folder from this ZIP.
4. Start the server again.
5. Open `/dashboard` and hard-refresh with `Ctrl + Shift + R`.

This release removes the remaining background, border, radius and shadow from the Owner Visual Site Studio editor work area. The Live Site Preview panel remains visible on the right.
