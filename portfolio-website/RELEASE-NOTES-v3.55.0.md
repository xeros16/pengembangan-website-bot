# PIR Visuals Website v3.55.0

- Adds a dedicated Owner Dashboard uploader for up to three homepage campaign slides.
- Homepage slides accept JPG, PNG, WebP, MP4 and WebM, with previews before saving.
- Homepage campaign media is stored independently; portfolio submissions and featured designer avatars are no longer auto-inserted into the banner carousel.
- Adds byte-range streaming for homepage video playback.
- Preserves original media aspect ratios in homepage, designer portfolio and upload previews on desktop and mobile.
- Adds a server-generated fallback preview for profile photos when the browser cannot decode the selected file.
- Changes profile saving to an AJAX submission with a redirect on success and clear error/timeout feedback.
- Adds a profile-saved confirmation message and bumps the public media stylesheet cache key.
