# Install update v3.61.4

1. Back up the existing website folder and database/uploads.
2. Stop the website server.
3. Replace the `portfolio-website` folder with the folder from this ZIP.
4. Start the server again.
5. Open `/dashboard` and hard-refresh with `Ctrl + Shift + R`.

This update removes the surrounding white field-wrapper panels in Headline & announcement, Copywriting setiap bagian, and SEO & social preview. The input boxes themselves remain visible and usable; the Live Site Preview is unchanged.
