# Catatan Perbaikan PIR Visuals Website v3.56.0

## Yang berubah
1. Foto profil yang dipilih akan langsung tampil sebelum tombol Simpan Profil ditekan. Pratinjau menggunakan data URL sehingga sesuai dengan kebijakan keamanan browser.
2. Avatar pada kartu direktori dibuat bulat, diposisikan dalam area header yang disediakan, dan label header diberi ruang agar tidak tertutup.
3. Gambar pada menu Jelajahi menggunakan tinggi otomatis dan rasio sumber asli; tidak lagi dipaksa ke rasio 4:5 atau dipotong. Bingkai kartu yang tidak diperlukan dihilangkan.
4. Beranda memiliki empat slot khusus untuk media karya pilihan. Owner dapat mengunggah JPG, PNG, WebP, MP4, atau WebM (maksimal 50 MB per file) melalui Dashboard > Visual Site Studio > Media karya pilihan Beranda.
5. Media pada bagian karya pilihan Beranda tidak lagi diambil otomatis dari portfolio desainer. Media portfolio tetap tampil di direktori dan halaman karya masing-masing.
6. Hero Beranda menggunakan artwork default PIR, bukan gambar karya portfolio pertama.
7. Kartu media Beranda dipaksa tetap terlihat jika animasi scroll tidak berjalan; rasio foto dan video mengikuti media aslinya di desktop dan mobile.

## Catatan penggunaan
- Setelah pembaruan, buka Dashboard Owner dan unggah media secara terpisah di bagian **Media karya pilihan Beranda**. Jika belum ada media yang diunggah, bagian karya pilihan Beranda tidak ditampilkan.
- Banner/campaign carousel tetap memiliki tiga slot media sendiri dan tidak digabung dengan empat slot karya pilihan Beranda.
- Upload profil tetap dibatasi 5 MB per file.
- Maksimal total payload formulir CMS per penyimpanan adalah 160 MB; bila mengunggah beberapa video besar, simpan dalam beberapa tahap.
