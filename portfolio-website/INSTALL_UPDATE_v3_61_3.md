# Install update v3.61.3

1. Back up the existing website folder and database/uploads.
2. Stop the website server.
3. Replace the `portfolio-website` folder with the folder from this ZIP.
4. Start the server again.
5. Open `/dashboard`, then hard-refresh with `Ctrl + Shift + R`.

This update removes only the white panels behind the field labels in **Copywriting setiap bagian** and **SEO & social preview**. The actual input and textarea controls remain white and bordered so they stay easy to read and edit.
