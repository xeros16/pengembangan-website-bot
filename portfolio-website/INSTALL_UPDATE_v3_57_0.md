# Update PIR Visuals Website v3.57.0

1. Backup the existing `portfolio-website` folder and database first.
2. Stop the website process (and bot if it launches the website).
3. Replace the existing `portfolio-website` folder with this package.
4. Keep the bot's `.env`, `uploads`, `auth_info_baileys`, and database unchanged. This update does not require a database migration.
5. Start the website/bot again and hard-refresh the browser with `Ctrl + Shift + R`.
6. Verify Discover Quick View, a designer profile's Selected Work, a project case-study cover, and the project-experience review form on desktop and mobile.
