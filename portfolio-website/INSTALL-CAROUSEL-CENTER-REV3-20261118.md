# Instalasi — Carousel Artwork Center Rev. 3

1. Backup folder website terlebih dahulu.
2. Ekstrak folder `portfolio-website` dari ZIP revisi ini ke root proyek website, lalu izinkan file website ditimpa.
3. Jangan menimpa `.env`, database, folder upload, atau data runtime instalasi lama.
4. Restart server website.
5. Buka ulang halaman Beranda dan lakukan hard refresh dengan `Ctrl + Shift + R`.

Revisi ini memperbesar gambar di kolom hijau desktop semaksimal mungkin tanpa crop atau mengubah rasio. Posisi tetap di tengah; teks kiri dan layout mobile tidak diubah.
