# Instalasi PIR Visuals v3.61.5 — Carousel Left-Only Inset

1. Cadangkan folder website yang sedang dipakai.
2. Ekstrak ZIP revisi ini.
3. Ganti folder website lama dengan folder `portfolio-website` dari arsip.
4. Jalankan ulang server.
5. Buka website dan lakukan hard refresh dengan `Ctrl + Shift + R`.

## Ruang lingkup
Revisi ini hanya menggeser konten sisi kiri pada panel teks carousel desktop. Padding kanan tetap, kolom gambar kanan tidak berubah, dan tampilan mobile tidak diubah.
