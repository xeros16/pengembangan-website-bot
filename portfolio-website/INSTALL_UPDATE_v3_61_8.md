# Instalasi Update PIR Visuals v3.61.8

1. Hentikan server website yang sedang berjalan.
2. Ekstrak ZIP revisi ini.
3. Ganti folder `portfolio-website` lama dengan folder `portfolio-website` dari ZIP.
4. Pertahankan `.env`, `auth_info`, dan `auth_info_baileys` dari instalasi lama.
5. Jalankan kembali `npm start` dari folder `portfolio-website`.
6. Buka website lalu lakukan hard refresh dengan `Ctrl + Shift + R`.

Revisi ini hanya mengubah alignment full-bleed carousel desktop agar kembali memenuhi lebar layar dan tetap terpusat pada area yang terlihat.
