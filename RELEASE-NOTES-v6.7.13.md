# PIR Visuals Bot v6.7.13

- Bundles PIR Visuals Website v3.60.0 with the standalone Community Showcase and expanded Owner Control Center.
- The homepage showcase has independent tabs for latest, featured, highest starting-price, lowest starting-price works, and Owner events.
- Owner dashboard supports creating, editing, approving, rejecting, featuring, replacing media, and deleting portfolio works; profile visibility/verification controls; and five Owner-managed event slots.
- Website package includes mobile-safe aspect-ratio handling, showcase navigation, Owner event media previews, and campaign click analytics.
- No database migration is required. Existing `.env`, authentication sessions, uploads, and backups must be preserved during update.
