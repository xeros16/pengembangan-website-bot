2. Buat salinan cadangan file berikut dari folder proyek:

   - features\commands\general-owner.js
   - tests\access-control.test.js
   - package.json
   - package-lock.json
   - docs\ACCESS-CONTROL.md
   - docs\commands.md
   - CHANGELOG.md
3. Ekstrak ZIP ini langsung ke folder proyek bot (contoh: E:\bot-grup-desain), lalu pilih Replace/Timpa untuk file yang diminta.
4. JANGAN hapus atau timpa .env, config\allowed-chats.json, config\allowed-chats.json.bak,

   folder backups, atau database MongoDB.
5. Dari folder proyek, jalankan:
   npm run check
   npm test
6. Jika kedua perintah lulus, jalankan kembali bot seperti biasa.
