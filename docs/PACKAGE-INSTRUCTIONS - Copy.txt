PIR Visuals Bot v5.90.0 — split source package

This source is split into Part 1 and Part 2 because of download size.
Download BOTH ZIP files, then extract both into the SAME empty destination folder.

different files; neither part is a standalone installation.

After extraction, run npm ci, then follow INSTALL_UPDATE_v5_90_0.md.
