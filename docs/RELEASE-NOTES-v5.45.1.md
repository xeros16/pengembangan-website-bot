# PIR Visuals v5.45.1 — Light Theme Correction

## Light theme
- Consolidated the light palette into a single final cascade layer to prevent legacy dark theme rules leaking into light mode.
- Reworked the palette to warm paper, neutral ink, muted sage and restrained gold.
- Normalized navigation, cards, buttons, form fields, tags, designer showcase, case studies, footer, availability states and discovery shortcuts.
- Improved body text, muted text, headings, links, button and input contrast.

## Dark theme
- Retained layered graphite/charcoal surfaces, ambient radial lighting and muted sage accents.
- No flat full-green treatment introduced.

## Reference direction
- The product direction remains a premium creative portfolio platform with editorial hierarchy and image-led case studies.
- This is an original PIR Visuals implementation, not a pixel-for-pixel copy of bettr.academy.

## Compatibility
- No database migration.
- No changes to Baileys, game modules, routes, CMS, uploads or portfolio data.
- Existing user theme preference storage remains intact.

## Validation
- Website syntax and tests run for this release.
