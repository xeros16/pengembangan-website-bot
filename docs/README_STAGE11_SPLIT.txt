PIR Visuals Bot v3.38.0 — Stage 11 Big Update

Rilis ini dibagi menjadi dua arsip ZIP yang saling melengkapi:
- PIR_Visuals_Bot_v3.38.0_Stage11_Bagian1.zip
- PIR_Visuals_Bot_v3.38.0_Stage11_Bagian2.zip

Ekstrak KEDUA arsip ke folder proyek yang SAMA. Jika diminta, izinkan penggabungan folder dan penggantian file yang identik. File konfigurasi utama disertakan di kedua arsip.

Setelah kedua arsip diekstrak:
1. Salin .env.example menjadi .env dan isi konfigurasi sendiri.
2. Jalankan npm install.
3. Jalankan npm run check.
4. Jalankan npm test.
5. Jalankan npm start.

Jangan bagikan .env, sesi autentikasi WhatsApp, atau data database.
