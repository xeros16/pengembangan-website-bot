PERUBAHAN UTAMA
1. CSP & INTERAKSI
- Menambahkan explicit script-src 'self' dan connect-src 'self'.
- Menjaga image-src self/data/https dan style-src self/unsafe-inline.
- Menghapus inline onclick/onerror/onsubmit dari HTML templates.
- Mengganti konfirmasi hapus, select link, dan fallback gambar dengan delegated event handlers first-party.
- Menambahkan tes bahwa seluruh browser bundles dapat diparse sebagai JavaScript.

2. PRIVATE COLLECTION LINKS
- Halaman collection yang memuat edit key selalu Cache-Control: no-store.
- Halaman edit key memakai Referrer-Policy: no-referrer dan X-Robots-Tag: noindex, nofollow.
- Halaman pembuatan collection yang menampilkan one-time edit link juga no-store/no-referrer/noindex.
- Response setelah update collection tetap no-store dan no-referrer.
- Public collection tanpa edit key tetap boleh cache publik selama 60 detik.

3. QR PAGE
- QR page sekarang menggunakan sendHtml() agar response security headers dan CSP sama dengan halaman lain.
- CSP mengizinkan logo lokal dan QR image HTTPS.
- URL target di atribut href di-escape.

4. HEALTH & SMOKE
- /health hanya menerima GET dan HEAD; method lain menerima 405.
- Smoke test sekarang memeriksa GSAP dan ScrollTrigger runtime agar dependency motion tidak diam-diam hilang setelah deploy.
