- Replaced the previous stacked landing-page layout with a new editorial creative-platform composition.
- New high-impact hero with custom typography, direct discovery CTA and live directory index.
- Retained dynamic CMS announcement and homepage carousel slides.
- Added four category discovery gateways wired to the existing directory category filter.
- Rebuilt featured designer section with new layout and responsive grid.

- New graphite/sage hero identity with warm neutral content surfaces.
- Distinct hierarchy, typography scale, spacing, borders and responsive compositions.

- Tablet/mobile layouts and reduced-motion support.

- Existing CMS homepage title, subtitle, announcement and carousel slides are retained.
