# PIR Visuals Bot — Panduan Pengguna v6.0.0

## Mulai

```text
.mulai
.mulai cepat
.menu
.cari bikin poster acara
.help contrast
.commands
```

Kamu tidak perlu menghafal semua command. `.mulai` memberikan rekomendasi sesuai kebutuhan dan tingkat pengalaman. `.cari` menerima kalimat sehari-hari.

## Akses cepat pribadi

Buka di chat pribadi dengan bot:

```text
.cepat
.cepat tambah contrast
.cepat tambah wizard
.cepat hapus contrast
.cepat bantuan
```

Untuk melihat perintah yang baru digunakan, aktifkan riwayat secara sukarela:

```text
.cepat riwayat aktif
.cepat riwayat lihat
.cepat riwayat nonaktif
.cepat riwayat hapus
```

Riwayat nonaktif secara default. Jika diaktifkan, bot hanya menyimpan nama command, bukan isi pesan, argumen, atau media. Maksimal delapan perintah unik disimpan.

## Direktori desainer

```text
.design
.design kategori Logo
.design gaya Minimalist
.design lokasi Bandung
.designer DSN-ID
```

Bot hanya menampilkan portofolio dan kontak publik. Hubungi desainer secara langsung. PIR tidak memproses pembayaran atau transaksi.
