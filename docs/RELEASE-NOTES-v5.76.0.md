# PIR Visuals v5.76.0 — Light Mode Contrast & Surface Refinement

## Ringkasan

Update ini berfokus pada keterbacaan dan konsistensi Light Mode di seluruh website PIR Visuals. Perubahan dibuat sebagai overlay terhadap project yang sudah ada; tidak mengubah alur bot WhatsApp, model database, maupun autentikasi.

## Perubahan utama

- Semantic palette Light Mode diperbarui: ivory canvas, warm-white surfaces, forest-green accent, dan muted text yang lebih gelap.
- Halaman Contact & Customer Support diperbaiki: teks italic heading, jam layanan, dan metadata kini memiliki kontras lebih kuat.
- Kartu `SUPPORT / 01` diubah dari lapisan abu-abu transparan menjadi permukaan pale-sage yang solid dengan teks gelap.
- Surface dan border pada card, panel studio, statistik, support channel, notes, form, tabel, shortlist, serta kontrol input diselaraskan.
- Placeholder, label, badge, navigasi, dan focus ring keyboard diperjelas.
- Dark Mode dan footer editorial gelap dipertahankan.

## Kompatibilitas

- Platform: v5.76.0
- Website: v3.30.0
- Service worker cache: `pir-visuals-public-v22`
- Cache-busting asset: `v=5760`
- Tidak ada perubahan schema database atau dependency graph.
