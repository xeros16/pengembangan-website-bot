# Private Portfolio Readiness — v5.99.0

Portfolio Readiness is a private checklist shown only inside the authenticated Designer Studio. It helps a designer see which public profile information may be incomplete.

## Score components

| Component | Points | Completion rule |
|---|---:|---|
| Identity | 20 | Display name, avatar, bio, and location (5 each) |
| Positioning | 20 | Main category (10) and at least one specialty (10) |
| Published portfolio | 25 | One approved work = 10; two = 18; three or more = 25 |
| Case study | 15 | Approved work with challenge + solution = 10; adding outcome = 15 |
| Direct contact | 10 | Public contact field is present |
| Active service | 5 | At least one active service |
| Creative story | 5 | Tagline, practice statement, or approach is present |

## Privacy and limits

- The checklist is rendered only in the authenticated owner's Designer Studio.
- The score is not stored in a public field and is not shown on public profile cards.
- Pending/rejected portfolio items do not count as published work.
- The published-work count is queried independently of the 30-item Studio preview list.
- This is a completeness checklist, not a visual-design critique, professional capability score, reputation score, popularity rank, or client-conversion forecast.
