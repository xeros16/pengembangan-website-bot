# Tutorial bergambar

Aset PNG yang dikirim oleh perintah tutorial:

- `portfolio.png` — membuat dan mengelola portofolio desainer.
- `order.png` — membuat brief, mengirim penawaran, memilih desainer, dan berbagi kontak.
- `proof-review.png` — pengiriman bukti, pemeriksaan Owner, revisi, konfirmasi, dan ulasan.

Perintah bot: `.tutorial portfolio`, `.tutorial order`, dan `.tutorial bukti`.
Konten teks utama berada di `content/texts.json` dan dapat diedit Owner melalui fitur editor teks.
