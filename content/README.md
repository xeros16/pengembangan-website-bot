# Konten yang dapat diedit

- `texts.json` menyimpan teks menu, bantuan, katalog, pesan perintah tidak dikenal, dan tutorial yang sudah dipindahkan dari kode.
- `backups/` dibuat otomatis saat Owner menyimpan teks melalui perintah editor.
- Jangan menghapus placeholder seperti `{prefix}`, `{total}`, `{categories}`, `{command}`, atau `{suggestions}` dari pesan yang menggunakannya, kecuali memang tidak ingin menampilkan nilai tersebut.

Panduan lengkap: `../docs/EDIT-BOT-TEXT.md`.
