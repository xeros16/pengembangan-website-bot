# PIR Visuals v5.53.0 — Signature Brand Background System

## Visual direction
- Introduced a brand-wide geometric linework background inspired by the supplied PIR Visuals discount poster.
- Added subtle intersecting diagonal line grids, oversized circular/orbit arcs and organic corner shapes.
- Light mode uses warm ivory/stone, taupe, olive and forest-green linework.
- Dark mode uses charcoal/deep forest, muted olive and low-contrast sage linework.
- Applied globally so public pages, designer studio, case studies and other page routes share the same visual identity.
- Added distinct linework treatment to homepage hero, work showcase and manifesto sections.
- Surface backgrounds remain sufficiently opaque to preserve legibility of forms, cards, tables, portfolio images and navigation.
- Responsive scaling reduces decorative geometry on smaller screens.
- Decorative layers do not capture pointer input and respect reduced-motion preferences.

## Compatibility
- CSS-only visual update in the website server-rendered style system.
- No database schema, collection, route, authentication, CMS, portfolio, support, analytics, Baileys or game behavior changes.
- Existing light/dark theme toggle remains the source of theme state.
